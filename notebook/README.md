# Notebook

One entry per line of inquiry (see `AGENTS.md`): what was asked, what was tried, what was
found, and what is still uncertain. Start here before reading the issues and pull requests
behind a line of inquiry; the notebook entry is the short version, they are the full record.

An entry is drafted once its line of inquiry's work, or a significant step in it, is done.
An LLM drafts it from the issue and pull request history; a person cuts it down to what is
worth keeping and approves it. Copy `TEMPLATE.md` to a new file named after the line of
inquiry's parent issue, for example `0009-adopt-conventions-for-working-with-agents.md`.

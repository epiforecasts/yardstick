# Notebook

Dated entries, newest first, one per update to a line of inquiry (see `AGENTS.md`). Each entry
is tagged with its line of inquiry, for example `[corpus]`, and links the issues and pull
requests it covers. An entry is never edited once merged; if later work changes what it says,
a new entry records that and names the entry it supersedes.

An entry records the reasoning the code and issue history don't show on their own: what the
work set out to do and why; what was done, described in terms of the question rather than the
commits; what was tried and dropped; how the question changed; and what is still uncertain. An
LLM may draft an entry, but a person reviews and edits the text before it is merged.
